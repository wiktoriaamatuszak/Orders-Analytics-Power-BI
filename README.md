# Analiza zamówień – Dashboard Power BI

Interaktywny dashboard stworzony w programie Microsoft Power BI, służący do analizy danych dotyczących zamówień oraz prezentacji najważniejszych wniosków biznesowych.

## Podgląd dashboardu

## Główne funkcjonalności

- Łączna liczba zamówień
- Kluczowe wskaźniki efektywności (KPI)
- Analiza zamówień w czasie
- Analiza statusów zamówień
- Analiza kategorii produktów
- Interaktywne filtry i segmentatory danych
- Analiza danych w ujęciu czasowym

## Wykorzystane narzędzia i technologie

- Microsoft Power BI
- DAX
- Power Query
